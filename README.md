Task 1: Exploratory Data Analysis (EDA)

📌 Project Overview

This project focuses on performing Exploratory Data Analysis (EDA) on the Superstore Sales dataset using Python.

The objective is to understand the dataset, identify missing values and duplicates, clean the data, analyze important patterns, and visualize insights.

🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

📂 Dataset

The project uses the Superstore Sales Dataset, which contains information about:

- Orders
- Customers
- Products
- Categories
- Sales
- Profit
- Regions
- Segments
- Order Dates

🔍 Steps Performed

1. Imported required Python libraries.
2. Loaded the dataset using Pandas.
3. Checked the dataset shape and column names.
4. Examined data types.
5. Identified missing values.
6. Checked for duplicate records.
7. Generated descriptive statistics.
8. Cleaned the dataset.
9. Removed duplicate records.
10. Handled missing postal code values.
11. Converted date columns into datetime format.
12. Saved the cleaned dataset.
13. Analyzed sales distribution using a histogram.
14. Identified sales patterns and outliers using a boxplot.
15. Analyzed total sales by category.
16. Created a correlation matrix using a heatmap.
17. Analyzed monthly sales trends.
18. Generated key business insights.

📊 Key Insights

- Technology generated the highest total sales.
- Technology also produced the highest overall profit.
- The Consumer segment contributed the highest sales.
- Sales data contains variations and potential outliers.
- Monthly sales analysis helps identify trends and changes over time.
- Correlation analysis helps understand relationships between numerical variables.

📈 Visualizations

The project includes the following visualizations:

- Sales Distribution Histogram
- Sales Boxplot
- Total Sales by Category
- Correlation Heatmap
- Monthly Sales Trend

3. Install the required libraries:

4. Make sure the dataset is placed in the correct "data" folder.
5. Run all cells in the notebook.
